## ⚠️ 主要發現

### 1. Rate Limiting 問題
**影響**: 17個測試失敗  
**原因**: 短時間內執行過多測試觸發 429 錯誤  
**建議**: 
- 在測試之間加入延遲
- 分批執行測試
- 使用不同的測試帳號

### 2. API 行為與文件不一致
| API | 文件預期 | 實際回應 |
|-----|---------|---------|
| JWT Token 登入（無效） | 400/401/403/302 | 500 |
| JWT Token 登入（缺少） | 400/302 | 404 |
| 註冊查詢（無效 Token） | 401/403 | 200 |

**建議**: 更新文件或調整測試預期值

### 3. 需要登入狀態的測試
**跳過的測試**: 5個  
**原因**: 需要真實 OTP 或有效登入 session  
**建議**: 
- 建立測試環境 mock OTP
- 使用固定測試帳號
- 實作自動化登入流程
