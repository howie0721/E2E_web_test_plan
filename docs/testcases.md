
# 會員登入（LOGIN）

## 手機號碼登入
### TC-LOGIN-0001-success
- **名稱**：手機號碼登入成功
- **說明**：輸入正確手機號碼與 OTP，應成功登入並導向會員首頁。
- **驗證點**：
  - 登入後顯示會員名稱或個人資訊。
  - 導航列出現「登出」按鈕。

### TC-LOGIN-0002-invalid-otp
- **名稱**：手機號碼 OTP 錯誤登入失敗
- **說明**：輸入正確手機號碼但 OTP 錯誤，應顯示錯誤訊息。
- **驗證點**：
  - 顯示「OTP 錯誤」或相關提示。
  - 不可登入系統。

### TC-LOGIN-0003-empty-fields
- **名稱**：手機號碼欄位為空登入失敗
- **說明**：手機號碼或 OTP 欄位留空，應提示必填。
- **驗證點**：
  - 顯示「請輸入手機號碼/OTP」提示。
  - 不可登入系統。

# 商品加入購物車（CART）

## TC-CART-0001-add-from-product
- **名稱**：從商品頁加入購物車
- **說明**：登入後於商品頁點擊「加入購物車」按鈕，商品應成功加入購物車。
- **驗證點**：
  - 購物車icon 顯示商品數量增加。
  - 購物車頁面出現該商品。

## TC-CART-0002-add-multiple
- **名稱**：重複加入同一商品
- **說明**：同一商品多次加入購物車，數量應正確累加。
- **驗證點**：
  - 購物車內該商品數量正確。

## TC-CART-0003-add-different-products
- **名稱**：加入多個不同商品
- **說明**：分別將不同商品加入購物車，購物車應顯示所有商品。
- **驗證點**：
  - 購物車內出現所有已加入商品。

## TC-CART-0004-persist-after-login
- **名稱**：登入後購物車狀態保留
- **說明**：未登入時加入商品，登入後購物車內容應保留。
- **驗證點**：
  - 登入後購物車仍有原先商品。

## TC-CART-0005-add-without-login
- **名稱**：未登入加入購物車
- **說明**：未登入時加入商品，應提示登入或將商品暫存。
- **驗證點**：
  - 顯示登入提示或暫存商品。
